## 🚀 Instalação

```bash
# Clonar repositório
git clone https://github.com/JulianoGarciaG/estudos-python.git
cd estudos-python

# Criar ambiente virtual
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Instalar dependências
pip install -r requirements.txt

# Iniciar Jupyter
jupyter notebook
```
